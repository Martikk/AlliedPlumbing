## Forms and free file handling — proposed architecture, not deployed

Confirmed destinations: Contact → info@allied-plumbing.ca; Quote → quote@allied-plumbing.ca; Careers → careers@allied-plumbing.ca.

Current live Formspree receiver is still shared. Setting a hidden recipient field is not secure routing. Existing email/resume-link alternatives remain available; PDF upload is not enabled.

Recommended no-additional-subscription option for modest volume: Google Apps Script HTML Service forms + private Google Drive storage + MailApp notifications. Host the file form with HTML Service and call its server with google.script.run; do not use opaque cross-origin `fetch(..., mode: 'no-cors')`, which cannot confirm acceptance.

Design requirements before switching:

1. Fixed server-side form-type → recipient map. Clients cannot choose recipient addresses.
2. Careers accepts PDF up to 5 MB; Quote accepts PDF/JPG/PNG up to 10 MB total. Validate size, extension, MIME and file signature server-side; reject unknown types. No executable/Office uploads.
3. Private Drive folder per purpose; no public links. Access only for the responsible team, explicitly approved before deployment.
4. Durable request ID and status record before notification; idempotency key for retries, lock around duplicate checks. Return success only after storage and notification acceptance. Mail API acceptance is not proof of inbox delivery.
5. Honeypot, request throttling, daily quota monitoring, and recovery email/phone when unavailable. No personal field contents in diagnostic logs or analytics.
6. Proposed retention: Careers 90 days; Quote attachments 180 days, subject to company approval. Scheduled cleanup moves expired files to Trash; permanent deletion and backup/mail retention require a separately agreed policy.
7. Three uniquely labelled test submissions, then confirmation in each actual business inbox. Test an oversized file, wrong type, network error, retry and duplicate. Keep current endpoint until all pass.

Google quotas vary by account and can change: https://developers.google.com/apps-script/guides/services/quotas . This is not unlimited or guaranteed free at any volume. HTML Service supports form file inputs as blobs: https://developers.google.com/apps-script/guides/html/communication . Google account authorization and access approval are required to deploy this backend.

In the GA4 web stream, disable Enhanced Measurement automatic form interactions and browser-history page views; the app sends explicit sanitized events. Verify `page_view`, `generate_lead` with `form_name` contact/quote/careers, and `phone_click` in DebugView. Never send names, email, phone values, messages, resume URLs, query strings or full referrers. Check no script/request before consent and no events after withdrawal. A browser-side event is not delivery evidence.
