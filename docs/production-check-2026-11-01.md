## Формы, доставка и файлы

- Все три типа временно отправляются на **alex@allied-plumbing.ca** по прямому указанию владельца. Публичные Contact/Quote/Careers адреса и подписи сохранены. Разделение на три разных inbox сейчас сознательно не используется.
- До временного перенаправления Contact, Quote и Careers принимали контрольные заявки, а владелец подтвердил доставку всех трёх писем в исходные рабочие ящики.
- После перенаправления сервер принял контрольную заявку `011126-074258-AF2F`; после включения на сайте — `011126-075040-C0B6`. Это подтверждает приём системой и принятие уведомления MailApp, **не подтверждает inbox-доставку именно на Alex**.
- Пользователь отправил Careers-заявку `28261fa2-43d3-4af9-be54-8caff5fd41ac`; браузер показал успех. Получение и открытие PDF как вложения пока отдельно не подтверждено.
- Quote: максимум 4 PDF/JPG/PNG, 10 МБ суммарно. Careers: 1 PDF до 5 МБ. Contact — без файлов. На сервере проверяются количество, размер, расширение, MIME и сигнатура; это не антивирусная проверка.
- Полный UUID остаётся внутренним ключом защиты от дублей; внешний reference имеет вид `ДДММГГ-ЧЧММСС-XXXX`, время America/Vancouver. Повторная заявка с тем же ключом получает сохранённый номер. Тест проверяет соответствие номера письму и архиву.
- Вложения закрыты в Drive аккаунта владельца. Contact/Quote переносятся в Trash через 180 дней, Careers через 90. Это не безвозвратное удаление и не очистка email-копий. Срабатывание ежедневного cleanup на реальных просроченных записях в этом проходе не проверялось.
- В ходе проверки исправлен реальный дефект: преждевременный disabled у fieldset мешал Apps Script считать поля. Исправление опубликовано с версии 2. В production используется версия 4.

## Как повторить

```sh
npm run lint
npm run build
npm test
npm run test:production -- /tmp/allied-production.json
```

Последняя команда делает GET-проверки. Она не отправляет заявки, не проверяет inbox и не загружает PDF. Серверные тесты Apps Script используют mock Drive/Mail; они проверяют логику, а не доступность Google или рабочей почты.
